# 导出规则

用户明确回复“导出”后，直接用 `export-reviewed` 打包已展示快照的每项最优候选（可以是历史版本），不再以质量状态、角落、模块残留、透明/尺寸/保护区或检查证据拦截，也不再次确认。保留原检查结论和候选选择理由。文件与展示哈希一致、路径位于项目内且可读取后即可打包，不替换成未展示的新版。

下列格式和质量要求继续用于生产与检查，以及未明确导出时的 `accept` / `deliver` 合格交付路径；不作为明确导出的附加门禁。

图标无外围空白：PNG 按完整 alpha 边界裁切，SVG 按真实渲染收紧 viewBox，流程见 [icon-content-bounds.md](icon-content-bounds.md)。透明孔洞和柔和笔画保留；汇总底色不属于素材。

PNG / lossless WebP 支持 alpha，裁去纯透明外围，保留阴影与半透明像素。trim 后记录 trim_offset 用于回填定位；若同时指定 size，size 是裁掉留白后的内容尺寸，必须保持此时的比例。

SVG 仅接受真实矢量，必须有正数 viewBox；脚本只允许静态基础图形和本地渐变/裁切引用，不允许脚本、外链、实体、style 或嵌入位图。SVG 的 size 是推荐显示尺寸，viewBox 不一定等于像素尺寸。SVG 无栅格缩略图时展示原图局部，并在宿主直接查看 SVG，不伪造渲染结果。

默认不放大原图。用户需要倍率版本时写明尺寸并检查比例，放大插值只能标记 resampled，不能标记真实细节提升。图标轮廓与复杂手绘不能强制矢量化。

`remove_background` 只适合用户明确选定的纯色边缘背景。算法只去除与图片边界连通且匹配颜色的像素，容差 0–30；不会自动去除封闭孔洞，也不保证半透明毛发/阴影无色边。用后必须视觉审核。复杂抠图交给原生图像编辑，不反复扩大容差。

九宫格 nine_slice 顺序 `[left,top,right,bottom]`，在最终导出像素尺寸上定义，四边大于 0，中心尺寸大于 0。输出九个 PNG 和 nine-slice.json。四角不伸缩，边缘沿单方向适配，中心按结构选择平铺或伸缩。复杂花朵独立分层。结构合法不代表接缝和实际页面布局已验证。

适配说明记入 adaptation，例如底部居中、保持宽高比、安全裁切区、最小容器尺寸、四角固定。实际页面环境缺失时只验证素材结构，报告 page_responsive_tested=false。不得输出前端实现代码。

普通按钮、圆形底托、规则边框与阴影按 composition-rules.md 留给代码；箭头/Icon 前景独立导出。插画需要适配可变高度时，记录等比锚点、安全裁切区和已经验证的高度范围。固定高度插画直接贴在增高卡片底部会露出原有圆角/背景接缝；必须检查并选择独立透明前景或经过安全裁切分析的等比覆盖方案。
