# 还原与质量

原图是视觉基准，核对整体构图、主色、主要对象及其比例/位置。明显新增或缺失一束花、一棵树、一条船等判失败；单个花瓣、细小斑点、笔触和纹理差异不作为失败理由。能直接提取就不重绘。

内容一致性比较排除明确登记的自动补角区；脚本生成 corner-completion-mask.png 和屏蔽该区的 content-comparison.png。排除区仍须单独检查是否铺满、是否有接缝或新增空带。像素保护检查只验证执行器没有改动应保留的原图，不要求未知补全部分逐像素一致。

自动检查覆盖文件可读、格式、尺寸、真实透明像素、空图、外围留白、比例约束、边缘接触风险及切片尺寸。简单裁切无变换时逐像素比较；WebP 使用 lossless。contrast_stddev 只是一项对比度指标，不能据此判定模糊。

视觉核对颜色/轮廓/细节/遮挡残留/阴影，与参考局部并排查看；SVG、生成/修复、去背景、上采样或边缘接触都需要审核。使用 visual-review 记录 note 和 verdict，保留自动 status；它不会自动代表用户通过。

重建结果不能宣称像素级一致，被遮挡的真实底图无法验证。issues/unknown 先修复复检；本轮结束通过 review-summary 展示每项一个最终候选，不显示内部质量状态，统一询问修改还是导出。质量记录、版本与导出校验仍保留。流程见 [quality-loop.md](quality-loop.md)。

同一轮最多两次实际处理/导入，包含首次。每次保存候选和问题；用户新修改才开启新轮，不能自行重置次数。

## 可见区域保真

`fidelity_regions` 坐标相对源图素材框。`{"box":[10,10,30,30],"kind":"preserve"}` 要求逐像素不变；`{"box":[0,0,10,10],"kind":"plain","color":"#faf7ef","max_mean_error":6,"max_outlier_fraction":0.01}` 检查纯底色偏差。plain 的明显偏色阈值为单通道差值 24；容差上限分别为 12 和 0.05，不准放宽以掩盖失败。只在确认的纯底色区域使用 plain；有纹理、图案或半透明内容不能冒充纯色。像素约束仅用于原尺寸位图，不用于 SVG、trim 或 resize。

背景、插画、纹理位图先执行 [surface-contract.md](surface-contract.md)：保留底边像素、修复源容器角落、分别检查新增留白与构图位置。保护原图像素不等于保护原容器圆角；需要去掉的容器片段必须明确进入修复区。

局部修复使用 `repair_regions`，坐标相对素材框，而非整张源图。支持矩形 `[left,top,right,bottom]`；圆角遮罩 `{"box":[...],"radius":17}`；字迹遮罩 `{"box":[...],"ink_threshold":185,"ink_mode":"dark","dilate":1}`。dark 选择亮度不高于阈值的字迹，light 选择不低于阈值的浅色字；膨胀 0–3 像素覆盖抗锯齿。字迹模式仅用于已可靠定位的文字框，不能套在包含复杂图案的整个区域。圆角模式不能与字迹模式混用。

原生结果按 [canvas-mapping.md](canvas-mapping.md) 的绑定关系回映到准确源尺寸；禁止任意拉伸和猜测裁切。执行器将结果仅合成到遮罩内，遮罩外逐像素使用原始参考，保存 repair-mask.png 并验证 protected_pixels_equal。遮罩外的保真不能证明遮罩内未知像素正确；必须检查修复边界是否有色块、残字、接缝。遮罩应贴合真实遮挡，不能用大矩形移除本可保留的纸纹或圆角外背景。

`matte_background` 是针对明确纯色背景的小图标的保守 alpha 恢复：保留不透明内部原色，边缘参考邻近前景颜色，去掉封闭背景孔洞。它不具备语义抠图能力；复杂纸纹、水彩、阴影和多重半透明叠加不得用此路径。务必在原底色和其他底色上查看，不能仅因存在 alpha 就判定正确。

修复产生未请求的透明洞、生成比例与原图不同，均属技术错误。保留区域、版本和正常确认门禁的回归测试必须保持通过。

## 无图案边界的融合

去字默认使用确认不含主要图案的完整文字窗口 `{"box":[...],"blend":"boundary"}`，连片消去文字及抗锯齿/高亮轮廓。圆形按钮可在精确完整窗口采用同样方法。脚本以周围未编辑的原图为边界，求解补片与原图之间的平滑色差场；保留补片的图案梯度、原图遮罩外像素和 alpha，记录收敛证据。不收敛则拒绝，不能回退硬贴。

字迹模式也先校色；若仍显字形轮廓，须重新分析完整窗口，不能擅自扩大遮罩。窗口包含需保护主体时应拆分或重定位，不能以连片修复抹掉主体。数值收敛不代表视觉通过，须实际检查残字、光晕和接缝。

先按 [composition-rules.md](composition-rules.md) 选择整体或分层背景。`background_join` 可从确认无主体图案的边界行开始延续颜色，平滑过渡到页面底色；`edge_blend` 仅调整确认无图案的纯色边带。两者不缩放图案，必须声明 `pattern_free:true`；这是需要模型检查的事实，字段本身不能证明区域干净。处理区域必须位于显式 `repair_regions` 内，否则保护区检查拒绝结果。不得把仍有山体/花枝的区域声明为纯色来掩盖截断。

融合后检查交接两侧的颜色、alpha 与纹理，以及实际短/长页面。规则渐变与纯色由代码实现；重建底色可能与原图纸纹有差异，必须保留严格比对结果。
