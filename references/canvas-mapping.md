# 工具画布与最终画布

`process` / `repair-queue` 为遮罩修复创建精确裁片和 square carrier。原裁片按整数倍放入方形载体，填充色固定，位置、缩放、文件哈希写入任务的 `canvas_mapping`。编辑目标使用该字段的 `file`；裁片用于原图对照，不能把整页作为编辑目标。

工具保持完整方形载体，只修改原裁片中的指定 UI、文字与缺角。原生输出可以是不同分辨率的方图。`fulfill` 依次：

1. 存档原始输出，计入本轮次数。
2. 校验绑定载体哈希、原图尺寸、原生宽高比与外围填充。宽高比只容许 1 个原生像素的取整差；填充平均通道色差不超过 8。
3. 按登记的 content_box 取样回原裁片尺寸。只移除登记填充，不自动 trim、不补白、不拉伸画面。
4. 仅合成已批准 repair_regions；遮罩外、原底边锚点逐像素保持原图。记录 canvas-mapping.json 和质量证据。
5. 对照精确原图检查 `canvas_alignment`：主体位置、比例、补角、接缝和底边。该项有疑点不能 passed；尺寸正确不代表内容合格。

工具若直接给出精确裁片尺寸可直接进入遮罩合成。旧任务没有载体时，仅允许等比例结果回采样，宽高取整差同样不超过 1 原生像素；其他比例须重新用载体任务生成。不能猜测哪里是额外留白。

比例、填充或视觉对齐失败，按原有两次循环修复，不通过更改清单尺寸、放宽阈值或重置计数解决。原生尺寸不同本身不再判失败，最终文件尺寸必须严格匹配源框。填充检查不证明图案位置正确，视觉对齐检查仍不可省略。
