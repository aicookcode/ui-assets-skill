# 严格复刻验证

本 skill 负责素材，页面代码由下游实现。本节用于用户要求验证“素材能否支撑代码严格复刻”的场景；不是每次普通导出都必须搭建页面。

## 先固定比较契约

记录目标页面在原图中的像素区域，排除用户不要的设备边框、状态栏、平台胶囊。确认字体是否必须相同；用户允许系统字体时，保留字形例外，但仍检查文字内容、位置、大小、行数、换行和重叠。默认不能添加字体例外来掩盖差异。

为不同职责分别收集证据：

- 素材：真实文件、尺寸、透明度、原图位置、版本和保留区域逐像素一致。
- 组合：下游页面实际浏览器截图，原始参考与渲染尺寸相同；禁止自动对齐或非等比缩放后再宣称通过。
- 布局：DOM 中组件框与参考坐标比较；检查图片等比、无溢出、内容/基本交互完整。
- 适配：手机窄屏、常规屏、高屏、宽屏；仅在所测屏幕内作结论。
- 动态组合：隐藏/插入模块、内容增高与入口重排。检查底图没有旧模块轮廓、图案等比且接底色连续，文字和独立箭头不重叠。把卡片增高后观察插画的实际接缝，不能只检查 DOM 坐标。
- 背景素材先单独显示，或隐藏全部业务模块检查整个背景，再看动态组合截图。发现旧模块色块即回到源 UI 范围和遮罩修复；不能仅因无溢出、等比和按钮可点击就结束验证，也不能用 CSS 新卡片盖住残留。

不能仅凭一个整体平均值判定；主要插画、卡片、背景等区域都必须单独比较。遇到纹理失真、遗漏素材、切断阴影或残留文案时，修改对应素材/拆分策略，再生成真实截图。

## 对比工具

```text
python scripts/compare_render.py --reference reference.png --actual render.png --render-background render-without-text.png --ignore-mask device-mask.png --config render-config.json --output evidence
```

`render-without-text.png` 来自同一真实页面暂时隐藏文字的截图，不能改变布局和背景。若字体完全一致，不设置 font_windows。device-mask.png 白色表示用户明确排除的设备部分，黑色表示必须比较的页面；它不能用于排除出错区域。

配置例子（坐标为比较截图的像素）：

```json
{
  "min_checked_fraction":0.85,
  "limits":{"max_mean_rgb_error":0.75,"max_p99_channel_error":8,"min_within_8_fraction":0.99},
  "font_windows":[{"box":[20,15,220,60],"mode":"dark","threshold":190,"expand":2}],
  "regions":[{"id":"illustration","box":[0,100,464,194],"limits":{"max_mean_rgb_error":0.05,"max_p99_channel_error":0,"min_within_8_fraction":0.999}}]
}
```

阈值是 0–255 通道差，需依据用户要求制定并记录，不能为掩盖失败而放宽。mean 是所有被检查 RGB 通道的平均绝对差；p99 是最大通道差的 99 分位；within_8 是最大通道差不超过 8 的像素比例。这些指标不是“相似度百分比”，也不证明像素级全等。

字体例外仅排除窗口内的字迹及最多 3px 抗锯齿邻域，不排除整个矩形。浅色文字在深色背景上须用 mode=light。渲染字迹优先由实际截图减去无文字截图获得，避免误把背景当成文字。窗口中若有山水/装饰等深色内容，需要进一步收窄窗口或不使用字迹例外，不能扩大窗口提高分数。

输出 report.json、实际被检查像素遮罩、字体/设备例外遮罩、并排对比和差异热图。报告记录源图/渲染图/例外遮罩的哈希及配置；退出码 0 表示所有区域通过，1 表示有失败。异常或不可判断不能视为通过。

## 用户授权的自动验收

分别报告组合规则、自动文件检查、严格截图比对的结论。组合测试通过不能替代严格视觉通过；严格失败时保留候选、热图和失败区域，不调用通过验收，也不把代码按钮改成整张位图以提高分数。

保留普通流程中所有确认门禁。仅在用户明确委托时，验证程序可按预设范围和限制调用同一命令，记录代理身份、约束、每次决定和版本；不能使用“接受差异”来绕过未解决的技术错误。

交付验证结论需同时给出页面、独立素材、可复跑脚本、对比证据、已修复问题及剩余限制。特定页面通过只证明本案例，不代表任意输入都能零误差恢复，也不能保证被遮挡的真实像素。
