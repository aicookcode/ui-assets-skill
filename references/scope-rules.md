# 范围解析

从当前任务相关历史信息中提取最新范围：图片编号、页面、位置/圈选、类别的交集。用户的新明确修改优先。原始图中同时含多页时，先查看实际像素定位页面，不按猜测平均分割。

标准表示：`{"text":"第3张图第2页，只要背景和 Icon","regions":[{"source":"source-3","page":"page-2","box":[400,0,800,900],"categories":["background","icon"]}]}`。

`regions` 是允许区域的并集；每个素材必须完全包含于至少一个匹配图片、页面、类别的矩形。圈选为不规则区域时，矩形记录包围框，圈选外内容需要独立 alpha mask 或原生图像编辑，不能把包围框内容都当成用户选择。

未指定时提供“是否需要补充切图范围？”及自然语言输入，选项“不补充，分析全图”“按指定范围分析”。聊天环境可使用简短选项，不要求用户填写。不要在用户回复前宣称全图已经批准。仅在范围无法可靠定位时进一步询问。

分批切图时保留既有项目。不在此次范围内的既有素材可在本次完整清单中暂设 selected=false；这只取消此次导出，不修改原始文件。若需保留旧素材同时分析新页面，scope 应包含旧、新素材区域。
