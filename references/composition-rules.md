# 可组合与动态布局规则

素材应保留设计的图案与材质，不保存业务模块的位置。静态截图相似只能验证一个状态；还要能隐藏模块、增减内容、改变容器高度而不暴露占位、接缝或被烘焙的控件。

## 先决定哪些不切

分析清单同时记录代码实现项：纯色/常规渐变、圆角、普通阴影、边框、圆形底托、简单加号及规则按钮。能合理用代码表达的结构不导出整张位图；微小噪声或像素分数不足，不构成把普通按钮整张截图的理由。只有无法表达且影响设计的艺术纹理可作为独立、可伸缩的纹理层，不能连字、箭头和按钮状态一起切。

箭头、Icon、徽标等前景图形与底托/插画/卡片分离。先判断前景能否用简单矢量可靠重建；否则只提取透明前景。重复箭头共享一个素材，颜色、大小和底托由使用方设置。装饰图内不得残留可独立定位或交互的箭头、Icon、刷新按钮、文案。检查最终页面是否真的使用独立 Icon；另导出一个未使用的副本不能代替拆分。

## 背景决策

先识别图案分布、纯色/纸纹区域、渐变方向、遮挡与边界颜色，再选择：

| 分布 | 优先策略 | 高度适配 |
| --- | --- | --- |
| 仅顶部有图案，向下渐纯 | 提取整张干净底图，保留图案到纯色的完整过渡，不沿图案末端硬截头部 | 图像按宽度等比、顶部锚定，纯色尾部接页面底色；新增高度用底色延伸 |
| 仅底部有图案，向上渐纯 | 提取整张干净底图，保留上方纯色到图案的完整过渡 | 等比、底部锚定，纯色头部接页面底色 |
| 上下均有图案 | 比较整张等比后的安全裁切、短屏可见性与上下关系；若不能适应高度变化，拆为顶部、底部及可扩展中间底色/纹理 | 两端分别等比锚定，中间延伸，禁止分别纵向压缩或把整图设为 100% 100% |
| 无图案，仅平色/规则渐变 | 由代码实现；真实不可替代的纸纹可输出不含位置线索的无缝小纹理 | 平色延伸或无缝平铺，不以整页模块阴影替代底色 |

先在 scope 中登记完整页面边界；多页合图为每页填写 page 与对应 box。background.canvas_box 必须匹配该页 scope，不允许用顶部图案框同时填写 box 和 canvas_box 来制造 full-base 通过。底图包含原页面的连续底色和必要过渡；“避免多余空白”不等于裁掉原页面本来的底色。

“整张底图”只能包含页面本来的背景图案及连续底色，不得保留卡片边框、模块阴影、白色矩形占位、箭头或其他业务布局痕迹。被遮挡区修复时，也要去掉模块投影；不能在旧模块区域填白块来制造通过截图的背景。

顶/底片和底色的交接需要检查 RGB/alpha、纸纹频率和渐变方向。使用匹配底色或仅在已确认无图案的区域修复/渐隐边缘；不能靠淡化主体图案掩盖接缝。两端图案可整张输出，但必须有短/长屏证据支持，不强制一律分层。

## 结构信息与门禁

装饰位图还必须填写并执行 [surface-contract.md](surface-contract.md)。规则中的“代码实现”要落实到具体源图边界、去除区域与保护区域，不能只作为 `decision` 的一句说明。

新清单的 `composition` 记录 role（background/illustration/icon/texture）、code_reproducible、decision、embedded_ui、layout_independent；背景再记录 pattern（top-only/bottom-only/both/none）、strategy（full-base/split-ends/whole-proportional/code-base）、base_color、scale、anchor。metadata 不能代替实际查看素材。

- code_reproducible=true 的结构不能以 PNG/WebP 整体导出；简单 SVG 前景可以独立导出。
- background 的 layout_independent 必须为 true，embedded_ui 必须为空。固定图案位置可以锚定页面，不能固定业务模块位置。
- illustration 也不得含 embedded_ui。局部文字/箭头遮挡修复只在显式区域进行。

## 验证

同时检查初始截图和动态变体：隐藏/插入一个模块、增高文案、长标题换行、移动入口顺序、短/长屏。断言图片等比、边缘接底色连续、背景没有旧模块轮廓、前景属于对应组件且不与文案重叠。代码能表达的普通控件不得为提高像素分数重新改为整图。
