# 视觉识别与拆分

根据确认原图识别背景、Icon、插画、装饰、卡片/按钮及复杂视觉组件。相同资源优先复用一个 ID，使用 relations 记录复用位置，不能只因名称相同便去重。

- 背景：将可伸缩底层、固定比例插画、角落装饰分层；记录定位关系和安全裁切区域。文字和 UI 遮挡处设 occluded=true，方法 repair/generate。局部预览只是原图截图。
- Icon：按 [icon-format.md](icon-format.md) 核对轮廓、细节及外观，填写 icon_policy。不可核对的内部标记不臆造；无法可靠保留原设计时回退源图 PNG。已有矢量源直接复用，透明边缘及有效阴影保留。
- 插画：复杂构图保持整体，独立复用部分才另拆，避免无用碎片。
- 卡片/按钮：普通纯色、圆角、规则边框只描述结构，不必列为图片。花朵等复杂装饰单独导出；边缘与中心可分且无复杂跨界图案时选择九宫格；不适合则分层。
- 无损裁切只有在框内所有内容都属于素材且无需抠图/修复时成立。含复杂背景的矩形截图不是透明 Icon。

清单展示 ID、中文名称、页面、源图框、局部预览、格式、预计尺寸、拆分方式和难度。用户全选/按类/逐项选择都落为 selected。修改后展示完整清单和更新标号。生成前不额外生图预览。

脚本裁切必须有明确像素坐标。先看完整原图，再查看必要局部；不能凭文字自动臆造坐标。素材来源不清楚时先定位，不执行生产。

严格还原时以真实截图反馈校正技术路径，同时遵守 [composition-rules.md](composition-rules.md)：常规按钮、渐变、高光、阴影、圆角和底托优先代码。确有不可替代的艺术纹理时只输出纹理，不连同箭头/文案/普通结构一起切；不能因微小噪声未匹配便改为整张位图。

大面积背景必须去除全部 UI、文字、卡片轮廓、模块阴影及占位块，能承受动态模块变化。单端图案的整张底图应保留到纯色的过渡；双端图案比较整体与上下分层的高度适配。背景的锚点、等比尺寸、接底色和安全裁切区写入 adaptation；不能把带业务布局痕迹的底图冒充可组合背景。
