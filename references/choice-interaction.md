# 选择交互规范

默认使用聊天中的编号列表，不自动展示内嵌面板、checkbox 页面、文件选择器或弹窗。用户已明确反馈这些方式无法直接查看，要求恢复编号选择。仅在用户再次明确要求时启用交互面板。

- 分析后在聊天中一次列出范围内全部候选，用 1、2、3 等连续编号标识，名称清晰，必要时补充格式与处理方式。
- 明确单选或多选；支持回复“全部”“1、3、5”“只要背景”等选择。编号须与稳定素材 ID 映射，不能将未回复当成确认。
- 支持直接补充拆分、合并、边界、格式及尺寸修改意见。修改后保留无关素材 ID 和选择状态，重新列出完整清单等待确认。
- 选择结果由模型写入 manifest 并执行正常批准流程；不能为使用编号而绕过分析、处理分流、参考保护或质量审核。
- 不要求用户打开 HTML、下载文件或进入浏览器才能完成选择。无需反复提供已无法显示的面板。
- 结果验收支持一次性通过全部，或按编号集中修改，不逐项要求点击通过。
